# `preview`

!!! abstract "Command information"
    Regular name **`preview`** :octicons-unlink-24:

    Other names **`pr`** :octicons-link-24:

    Introduced in version **v0.2** :octicons-tag-24:

## About

The `preview` command is used to display the **syntax highlighted** file area of the **current stack frame**.

## Notes

!!! warning
    The program must be in the `SUSPEND` state.

## Syntax

This command accepts **no arguments**.
